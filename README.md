# AgenticRecon

Automated Texture-Guided Hyperparameter Optimization
for CT Reconstruction

## Overview

AgenticRecon is a retraining-free framework for
organ-specific, case-adaptive CT reconstruction
using external GLCM texture references.

The framework includes:
- Ours 1: Organ-specific scalar Bayesian optimization
- Ours 2: Feature-resolved Gaussian-process optimization
- LangGraph-based reconstruction workflow orchestration
